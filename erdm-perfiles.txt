# ============================================================
#  erdm-perfiles.txt  —  qué contiene cada versión del modpack
#
#  UN SOLO modpack. Esta lista es un FILTRO que se aplica en la
#  máquina de cada jugador en el momento de la descarga.
#
#  Todo lo que NO aparezca aquí va en las dos versiones.
#  Lo que aparezca en [solo-graficos] se le quita a "Esencial":
#  no se descarga, no se carga, no ocupa RAM.
#
#  ---------------------------------------------------------
#  CÓMO EDITARLO
#  ---------------------------------------------------------
#  Un nombre por línea. El nombre es el del METAFILE sin la
#  extensión .pw.toml  (p. ej. "subtle-effects", que es
#  mods/.index/subtle-effects.pw.toml).
#
#  Se usa el nombre del metafile y NO el del .jar a propósito:
#  el .jar cambia de nombre en cada actualización del mod, el
#  metafile no. Si aquí pusiéramos nombres de .jar, la lista se
#  rompería en silencio con cada update.
#
#  Las líneas que empiezan por # son comentarios y se ignoran.
# ============================================================
